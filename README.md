
# 🇺🇸 US States Learning Game (2-Level HTML5 App)

This is an interactive, accessible web-based learning tool designed for grades 4–6 to master U.S. state-capital pairs and explore key geographic features of each state.

## 🎮 Quick Access to Game

👉 [Click here to start the game](US_States_2Level_Game.html)

## 🎮 Features

### Level 1: Match & Memorize
- Type a U.S. state and receive the correct capital.
- Instant visual and audio feedback (TTS).
- Ideal for memorization and practice.

### Level 2: Explore Geography
- In addition to capitals, learners see a brief geographic description.
- Learner-centered discovery with immediate feedback.
- TTS helps reinforce auditory learning.

### ✅ UDL-Aligned Design
- Multiple means of representation (text, speech, visual map).
- Multiple means of engagement (self-paced interaction, gamified input).
- Multiple means of action (type, listen, choose levels).

### 🔊 Accessibility
- Offline-capable (no backend required).
- Compatible with screen readers and keyboard navigation.
- Fully HTML5 & JavaScript – deployable anywhere.


# 🇺🇸 US States Learning Game（中英教学版）

本互动式网页教学工具适用于小学四至六年级学生，旨在通过两级练习帮助学生掌握美国50个州及其首府的英文拼写、中文名称与地理位置。

---

## 🎯 教学目标

- 识别与拼写美国州名及首府（英文）
- 理解其中文含义与地理特征
- 通过听觉、视觉、输入等多感官方式巩固学习

---

## 📚 教学内容结构

### Level 1: 州与首府对照练习（中英双语）

- 输入英文州名与首府
- 自动对比答案并给予反馈
- 鼠标悬停或输入完成后播放标准美音
- 点击 Hint 可查看中英教学提示

### Level 2: 州地理扩展练习

- 输入州名，获得其首府与地理描述（英文）
- 适合进阶延伸学习与州项目拓展活动

---

---

## 👩‍🏫 教学建议

- 启动主页面（US_States_2Level_Game.html）
- 鼓励学生选择英文或中英练习界面（Level 1）
- 可进行小组竞赛或打字比赛
- 配合纸质地图使用效果更佳
- 可延伸 Level 2 作为地理写作任务（如描述州名含义、位置、文化）
