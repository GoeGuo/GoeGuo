## 🌟 Features | 功能特色

### ✅ Level 1: Match & Learn (English)
- Practice matching 50 U.S. states with their capitals
- Text-to-speech for correct American English pronunciation
- Click 💡 Hint to see fun facts per state

### ✅ Level 1 中文对照版
- 中英文对照：州名与首府均显示英文+中文
- 支持朗读纯正美音
- 提供适合学生阅读的文化小知识提示

### ✅ Level 2: Geographic Explorer | 地理探索模式
- 输入州名自动显示：
  - 🏛 首府名称
  - 🗺 地理特征
  - 💬 文化小知识
  - 🔊 首府朗读发音
